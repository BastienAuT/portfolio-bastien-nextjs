# Portfolio Bastien Autem

Portfolio développé avec Next.js, React, Tailwind CSS et Bun.

## Prérequis

- Bun 1.3.14 ou plus récent
- Node.js 20.9 ou plus récent pour la compatibilité Next.js

## Installation

```bash
bun install
```

## Développement

```bash
bun dev
```

Le site est ensuite disponible sur `http://localhost:3000`.

## Vérifications

```bash
bun run lint
bun run build
```

## Production

```bash
bun run build
bun start
```
